| Term                 | Summary    | Description                                       |
| -------------------- | ---------- | ------------------------------------------------- |
| **Project Charter**  | Why        | "Why are we doing this project?"                  |
| **Project Manifest** | What + How | "What is this project and how do I work with it?" |


```
Project Charter
├─ Business purpose
├─ Scope
├─ Success criteria
├─ Sponsor
├─ Funding / approval
└─ Authority to proceed

Project Manifest
├─ Project inventory
├─ Components
├─ Dependencies
├─ Configuration
├─ Runbooks
├─ Usage instructions
└─ Structure / navigation
```

## Project Charter
More common in project management (PMBOK, governance, steering committees).
Its purpose is to formally authorize and align the project.

## Project Manifest
More common in software, data, DevOps, and AI projects.
The term comes from the idea of a "shipping manifest" or "inventory manifest".
Its purpose is to describe the project's contents and operational structure.
